# Python Calculator

A simple command-line calculator built with Python.

This project was created as a beginner Python programming project
to practice functions, loops, conditional statements, user input,
error handling, Git, and GitHub.

---

## Project Objectives

The main objectives of this project are to:

- Learn the basics of Python programming
- Understand how Python functions work
- Practice conditional statements
- Practice loops
- Handle invalid user input
- Handle division by zero
- Learn Git version control
- Upload and manage a project on GitHub

---

# Features

The calculator supports four basic arithmetic operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division

It also includes:

- Invalid menu selection handling
- Invalid number input handling
- Division-by-zero protection
- A loop that allows multiple calculations
- An option to exit the program
